# TrollTips
Installs TrollStore directly to Tips.app, removing the need for a persistence helper using a modified TrollInstallerX IPA.

# READ THIS
-When prompted to install a persistence helper, scroll down to the bottom and select "No persistence helper"
-After the install finishes, there will be 2 TrollStore apps on your home screen. Remove the one that was NOT installed to the Tips app by going into trollstore settings and hitting uninstall trollstore then preserve apps, this will leave you with a single Trollstore installed in the Tips app.
